🚗 ANALISIS RUTE PERJALANAN

📖 Cara pakai
  • 🎨 Tombol 🌙/☀️/🌃 di pojok kanan atas: ganti tema GELAP, TERANG, atau MALAM (mode pasar gelap berkendara — hitam + amber, nyaman di mata malam hari). Pilihan tersimpan otomatis.
  • 🗺️ Tombol PETA / SATELIT / GELAP di kiri atas: ganti peta dasar (semua tanpa API key).
  • 🔎 Cari kota → peta melompat & panel cuaca menampilkan kondisi nyata.
  • 👆 Klik peta di titik mana pun → cuaca koordinat itu.
  • 🎞️ Bar radar bawah: animasi hujan nyata (±2 jam lalu + prediksi 30 mnt, berlabel PREDIKSI).
  • 🚗 Isi asal & tujuan → ANALISIS: rute jalan nyata + cuaca di 7 titik perjalanan.
  • 🗺️ Mini-map kiri bawah: gambaran seluruh rute + kotak posisi layar. Klik mini-map untuk melompat.
  • 🟩 aman · 🟨 waspada · 🟥 bahaya.
Sumber data nyata & tanpa API key: RainViewer (radar presipitasi global) · Open-Meteo (model cuaca) · OpenStreetMap / Esri / CARTO (peta dasar) · OSRM (rute jalan). Butuh koneksi internet. Bukan simulasi.
